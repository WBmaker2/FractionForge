# 업데이트 내역

## 2026-11-06

- 앱을 처음 완성했어요. `index.html` 파일 하나만 있으면 실행돼요. 인터넷이나 로그인이 필요 없어요.
- 시작 화면에서 3학년 또는 4학년을 고르고 '학습 시작하기'를 누르면 공부할 수 있어요.
- 활동 A '똑같이 나누기': 원과 막대 그림을 눌러 목표 분수를 직접 만들어 보세요. 빈 도화지에서 시작해요.
- 활동 B '어느 게 클까': 두 분수를 그림과 숫자선으로 보고 `>`, `<`, `=` 중에서 고르세요. hint 버튼을 누르면 3단계로 도와줘요.
- 활동 C '조각 모으기': 분모가 같은 덧셈·뺄셈 답을 `3/4`처럼 적어 보세요. `1` 같은 자연수도 돼요.
- 정답은 사람이 미리 적어 두지 않고, 앱 안의 분수 계산기가 직접 계산해요.
- 결과 화면에서 점수·정답률·틀린 문제 다시 보기를 볼 수 있고, '다시 하기'로 또 풀 수 있어요.
- 중간에 새로고침해도 점수와 순서가 그대로 이어져요. 기록은 이 기기에만 저장돼요.
- 다음 단계 버튼에는 금빛 반짝임(펄스)이 있어 어디를 눌러야 할지 알 수 있어요.
- 시작 화면 오른쪽 위 '업데이트 내역' 버튼을 누르면 이 내역을 오래된 순서대로 볼 수 있어요.
- **[v1.1.0 품질 마무리]** 계산기가 스스로 검사하는 `?selftest=1` 화면을 넣었어요 (10가지 검사, 전부 통과해야 정상).
- **[v1.1.0 품질 마무리]** 활동 A에서 틀린 시도도 기록해요. 결과 화면에 "n번 만에 맞혔어요!"가 나오고 오답 복습이 더 정확해졌어요.
- **[v1.1.0 품질 마무리]** 결과 화면에서 새로고침해도 결과가 그대로 보여요. 이어하기도 더 정확해졌어요.
- **[v1.1.0 품질 마무리]** 작은 휴대폰 화면(375px)에서도 옆으로 밀리지 않아요. 글자 색을 진하게 해서 잘 보이게 했고, 키보드만으로도 끝까지 할 수 있어요.
- **[v1.1.0 품질 마무리]** 선생님용 안내서(`README.md`)를 넣었어요. 쓰는 방법과 기록 지우기가 적혀 있어요.
- **[배포]** 깃허브에 코드를 올리고 누구나 접속할 수 있게 배포했어요. 주소: https://WBmaker2.github.io/FractionForge/
- **[v1.1.2 오류 수정]** 활동 B에서 분수 대신 `1`이 나오는 문제를 고쳤어요 (10번 중 3번꼴로 나왔어요). 이제 두 분수가 항상 제대로 보여요.
- **[v1.1.2 오류 수정]** `1`처럼 꽉 찬 원 그림이 세로 선처럼 깨져 보이던 것을 동그랗게 고쳤어요.
- **[v1.1.2 오류 수정]** 활동 C에서 `2/9 + 3/9`가 `2/9 + 1/3`처럼 다르게 보이던 것을 고쳤어요. 이제 "분모가 같아요"라는 설명과 그림이 일치해요.
- **[v1.1.2 개선]** 덧셈에서 분모까지 더하면(예: `1/6+1/6` → `1/6`) "분모까지 더했나요?"라고 알려줘요.
- **[v1.1.3 화면 정리]** 활동 화면의 순서를 읽기 쉽게 정리했어요. 위에서부터 상태 → 제목 → 문제 → 조작(도형·버튼) → 피드백 → 다음 버튼 순서로 보여요.
- **[v1.1.3 화면 정리]** 활동 A에서 분모 버튼을 도형 위로 올렸어요. 몇 등분인지 먼저 정하고 색칠하는 순서가 자연스러워졌어요.
- **[v1.1.3 화면 정리]** 카드 안의 간격을 일정하게 맞췄어요. 제목과 문제는 가깝게, 각 부분 사이는 넉넉하게 띄워서 눈이 편해졌어요.
- **[v1.1.3 화면 정리]** 작은 휴대폰에서도 버튼과 입력칸이 세로로 쌓여서 옆으로 밀리지 않아요. 크기 비교 버튼은 가운데에 모았어요.
- **[v1.1.4 손가락 배려]** 도형 그림이 화면에 맞게 커졌어요. 분모가 12개여도 조각을 누르기 쉬워졌어요.
- **[v1.1.4 손가락 배려]** 태블릿에서 빨리 두 번 누르면 화면이 확대되던 것을 막았어요.
- **[v1.1.5 제목 버튼]** 위쪽 제목(로고+분수 공작소)을 누르면 시작 화면으로 돌아가요. 풀던 문제는 그대로 있고 '이어서 하기'로 돌릴 수 있어요.

## 2026-11-05

- 프로젝트를 처음 만들었어요. 영문 이름은 **FractionForge**, 한글 이름은 **분수 공작소**로 정했어요.
- 초등 3~4학년이 분수와 분수 연산을 직접 조작하며 배우는 교육용 웹앱을 만들기로 했어요.
- 어떻게 만들지 적은 **구현 계획서(IMPLEMENTATION_PLAN.md)** 를 넣었어요.
- 이 앱은 인터넷 연결이나 API 키 없이 `index.html` 파일 하나만으로 혼자 실행되도록 계획했어요. 그래서 학교 컴퓨터나 태블릿에서도 그대로 쓸 수 있어요.
- 아직 앱 화면은 만들지 않았어요. 이 폴더에는 계획만 들어 있고, 실제 만들기는 데스크톱 앱에 등록된 프로젝트에서 진행할 예정이에요.
