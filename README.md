# 분수 공작소 (FractionForge) — 교사용 안내

초등 3~4학년 분수 학습용 **오프라인 웹앱**입니다. 파일 하나(`index.html`)로 동작합니다.

## 실행 방법

1. `index.html` 파일을 더블클릭하면 웹 브라우저에서 바로 열립니다.
2. 인터넷 연결, 로그인, 설치가 필요 없습니다.
3. 배포된 주소로도 바로 쓸 수 있습니다: https://WBmaker2.github.io/FractionForge/

## 학교에서 쓰는 방법

- **USB 복사**: `index.html` 파일 하나만 복사하면 됩니다.
- **학교 누리집(LMS)**: 파일을 그대로 올리고 링크하면 됩니다.
- **태블릿·스마트폰**: 가로 375px 작은 화면에서도 깨지지 않습니다.

## 수업 흐름

1. 시작 화면에서 **3학년**(분수 개념·크기 비교) 또는 **4학년**(같은 분모 덧셈·뺄셈)을 고릅니다.
2. **활동 A 똑같이 나누기** → **활동 B 어느 게 클까** → **활동 C 조각 모으기** → **결과** 순서로 진행합니다.
3. 금빛으로 반짝이는 버튼이 다음에 누를 곳입니다.
4. 결과 화면에서 점수·정답률·틀린 문제 다시 보기를 확인하고 **다시 하기**로 반복할 수 있습니다.

## 기록과 지우기

- 점수와 이어하기 기록은 **학생의 기기(브라우저)에만** 저장됩니다. 서버로 보내지 않습니다.
- 중간에 새로고침해도 점수와 순서가 이어집니다. 결과 화면에서 새로고침해도 결과가 유지됩니다.
- 기록을 지우려면 시작 화면의 **기록 지우기** 버튼을 누릅니다.

## 자가 점검 (고장 확인용)

- 브라우저 주소 뒤에 `?selftest=1`을 붙여 열면(`index.html?selftest=1`) 분수 계산 엔진이 스스로 10가지 검사를 하고 결과를 표로 보여줍니다. 전부 통과해야 정상입니다.
